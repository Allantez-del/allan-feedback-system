# API and DynamoDB Design

## DynamoDB Item Design

The customer feedback system stores each feedback submission as one item in Amazon DynamoDB.

The partition key is:

`feedbackId`

Example item:

```json
{
  "feedbackId": "fb-8f3a21",
  "customerName": "Jane Doe",
  "email": "jane@example.com",
  "rating": 5,
  "category": "service",
  "message": "The customer support was very helpful.",
  "submittedAt": "2026-08-27T17:30:00Z"
}
```

## Field Definitions

- `feedbackId` — generated by AWS Lambda and used as the DynamoDB partition key
- `customerName` — optional customer name
- `email` — optional customer email address
- `rating` — required integer from 1 to 5
- `category` — required feedback category
- `message` — required feedback message
- `submittedAt` — timestamp generated by AWS Lambda

## Allowed Categories

The following categories are allowed:

- service
- product
- delivery
- website
- complaint
- suggestion
- other

## API Endpoint

`POST /feedback`

The endpoint accepts a customer feedback submission.

## Successful Request Example

```json
{
  "customerName": "Jane Doe",
  "email": "jane@example.com",
  "rating": 5,
  "category": "service",
  "message": "The customer support was very helpful."
}
```

## Successful Response Example

HTTP status:

`201 Created`

Response body:

```json
{
  "message": "Feedback submitted successfully.",
  "feedbackId": "fb-8f3a21"
}
```

## Invalid Request Example

The following example contains an unsupported feedback category:

```json
{
  "customerName": "Jane Doe",
  "email": "jane@example.com",
  "rating": 5,
  "category": "unknown",
  "message": "Example feedback."
}
```

HTTP status:

`400 Bad Request`

Response body:

```json
{
  "message": "Invalid category."
}
```
